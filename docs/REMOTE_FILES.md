# 远程文件下载

本次适配先核对 ChatGPT Android 1.2026.307 的原生实现，再对照用户的两段录屏。完整安装包、反编译文件、录屏和截图保留在受控产物区，不随源码分发。

## 原生依据

- `p2e1.f → p2e1.b → e8m → gva`：普通远程文件使用底部弹层；HTML 是单独的全屏分支，不能以其作为 PDF/Word 的布局依据。
- `lp0`：内容水平 32dp、垂直 24dp；标题 16sp/24sp/600，正文 16sp/24sp/400，元数据 12sp/16sp/400；工具按钮容器 32dp、图标 24dp、按钮间距 8dp、标题下方间距 16dp。文件名/大小和路径之间使用 8dp 间距，路径最多五行。
- `p2e1.c`：加载、失败、加载完成是不同状态。加载时 24dp/2dp 进度环及“正在通过远程控制读取此文件。”；录屏的 PDF/Word 使用不支持预览文案，不显示二进制原文。
- `lp0`、`ivl`：下载按钮在加载完成后出现；打开按钮由已有的保存记录决定，与扩展名无关，重新加载时也可以出现。
- `gtl → p5 → i68 → zh1 → m81`：成功写入 `MediaStore.Downloads` 后，只关闭仍对应当前文件/请求的弹层，保留下载 URI，提示“已保存到‘下载’文件夹”并提供“打开”；写入失败删除此次未完成记录。
- `xqd1.m`：打开是带 MIME、读取授权及 ClipData 的 `ACTION_VIEW` 系统选择器，不是分享，也不在下载完成后自动启动。
- `gva.c → rmj0.u → mdz0`：Android 12+ 优先取设备屏幕圆角，仅四角相同且非零时采用；其他情况顶部 24dp，底角为零。不能把录屏圆角当成固定原生常量。

原生主题背景和遮罩有明确 token，但尚未证明当前运行时的精确 RGBA；导航栏 inset 的完整调用链也未完全展开。实现采用本项目浅色主题和系统 inset，并通过真机截图核对，不声称所有主题/系统一比一。

## 本项目实现边界

文件读取使用已认证的 SSH/SFTP，流式落到本次请求的私有临时文件，再保存到手机的下载目录；不受原先 8 MiB 内存预览上限限制。预览、保存和异步回调绑定连接身份及请求，取消、断线和文件变化不能产生成功提示。

图片继续使用既有图片查看器；可识别的代码/纯文本保留有限长度预览。PDF、Word 等二进制文件提供下载和系统打开。本次没有增加 HTML 执行或视频播放器。Android 10+ 使用 Downloads；Android 8/9 使用系统文件选择器兼容保存，这属于本项目兼容逻辑，原包仅支持 Android 10+ 的远程文件下载。

本次证据入口：Debian 受控产物区内的相对归档标识 `codex-mobile/20261116-file-download/`，实际根目录见本机私有 `work/local-environment.md`。构建、目标机验证和未覆盖项见对应版本验证记录。
