# codex cli app

原生 Kotlin / Jetpack Compose 手机客户端。通过带 SHA-256 主机指纹校验的 SSH 连接服务器上的 `codex app-server daemon` / `proxy`，复用服务器的模型提供方、URL、API Key 与聊天历史。手机中不包含模型提供方的 Key，也不需要 ChatGPT App 登录。

当前源码版本为 **0.2.21 / code24**。公开 APK 由 [GitHub Actions](https://github.com/jinshenganyuci/codex-cli-app/actions) 每小时检查 `main`，发现新版本才自动构建并发布到 [Releases](https://github.com/jinshenganyuci/codex-cli-app/releases)；以 Releases 实际已发布版本为准。公开 APK 仅通过 GitHub 更新，不内置私人服务器地址或激活邀请。

## 使用

支持连接你自己的云服务器或局域网电脑。填写的是 SSH 连接，不是模型 API / HTTP / WebSocket 地址；远端需先安装并配置兼容的 Codex CLI。完整步骤见 [连接自己的 Codex](docs/CONNECT_YOUR_CODEX.md)。

在“Codex → 添加连接”或“设置”中添加服务器地址、SSH 用户和可信主机指纹，导入私钥或选择密码认证。SSH 凭据通过 Android Keystore AES-GCM 加密保存在应用私有数据中。服务器需要支持 `codex app-server daemon start` 和 `codex app-server proxy`；本轮使用 Codex CLI 0.169.0 验证。

连接后可打开和继续已有聊天，选择项目目录、模型、推理强度与权限，发送文字和附件，查看流式输出、命令详情、文件修改与任务进度，并处理请求。应用不包含语音入口。关闭手机连接不会停止服务器后台 App Server。

0.2.1 修正生成图片与照片显示：支持 App Server 的裸 base64 图像结果、远程照片缩略图、生成中占位、全屏缩放、复制与原图保存。图片按 APK 原生组件默认最大 280×350dp 等比显示，未知尺寸占位为 280×280dp；图片加载、缩放与 EXIF 方向处理在后台执行。图片缓存按服务器连接隔离，限制图片字节和缓存大小；未知工具详情使用有界文本预览。

0.2.2 修正输入法弹出及输入栏变高时的聊天底部跟随；用户上滑历史会暂停跟随，回到底部或主动发送后恢复，流式回复不强拉历史阅读位置。模型、推理与权限菜单保留输入法，并处理子菜单返回。同一用户消息中的连续图片按原生规则组合：2/4张两列，其他多张三列，间距8dp；每张均可打开原图。

0.2.3 增加前台自动检查更新。每次打开/真正回到 App 前台检查一次，通过当前保存的 SSH 连接独立读取同一服务器上的更新索引，不要求 App Server 已启动。发现新版后显示版本说明，由用户选择下载；下载校验大小、SHA-256、包名、版本及当前签名一致后，交给 Android 系统确认安装。第一次安装支持更新的版本仍需手动覆盖原包；之后的新版本可在 App 中获取。自动检查失败不阻塞聊天，下载失败可重试或取消。

更新目录为 SSH 用户 home 下 `.local/share/codex-mobile/updates/`，版本索引为 `latest.json`，APK 保存在 `releases/`。局域网与已有公网 SSH 入口使用同一套认证。没有配置连接时，保存有效连接后才开始本次检查；后台文件缺失或不是本项目更新格式时不展示错误更新提示。

0.2.4 增加聊天列表长按菜单：置顶／取消置顶、重命名、移至分区、新建分区、标记为未读、复制对话串 ID 和归档。置顶使用服务器内建 Pinned 分区；分区、已读状态、名称和归档都通过实际 App Server 接口保存。分区只整理聊天列表，不移动项目文件或改变工作目录。打开未读聊天后，按实际读取的版本标为已读；并发冲突只刷新状态，不盲目覆盖另一端的新状态。菜单始终操作长按的聊天，不依赖上次打开的聊天。

0.2.5 在归档下增加带确认的永久删除，使用服务器原生 `thread/delete`，删除聊天及其子代理记录，项目文件不受影响。后端拒绝删除时保留错误和当前聊天；不以归档替代删除。删除能力按已验证服务器版本启用，未确认的服务端不会显示为可用。新建空聊天不提前加载尚不存在的历史；同一客户端明确知道尚未发送的草稿在重连时可恢复输入内容，不重发已经提交的消息。

项目标题支持长按“从列表移除”。按用户要求，这只影响本手机的“按项目”列表，保留所有聊天与服务器文件；其他分组和搜索仍可查看聊天。移除记录按连接身份及精确目录隔离，刷新、重启后保留；Codex标题菜单中的“已移除的项目”可恢复列表显示。

输入框的编辑状态与文字、附件内容分开：未编辑时收窄并保持圆润外形，点击输入后展开；上传图片不自动强制进入编辑状态。文件更改汇总优先使用原 App 同一 `gitDiffToRemote` 接口，点击可查看文件、增删行和行号。没有远端等原生读取失败时，使用只读本地 Git 差异并注明“相对上次提交”；必要时仅展示带“本轮”标记的真实回合差异。读取失败不伪装成“没有更改”，也不把历史中反复编辑的文件简单累加。大于512 KiB的已接收差异不生成不完整统计；原生接口自身没有输出上限，极大仓库仍受传输限制。

旧版本的本机置顶标记保留兼容；服务器已有自定义分区时，以服务器分区为准，显式置顶或移动成功后清除对应旧标记。草稿与已跳过计划状态仍保存在本手机。默认权限、自动审核、只读和完全访问是下一次发送时提交的服务器策略；已有聊天打开时从服务器恢复实际配置，非标准组合显示为自定义而不伪装成某种预设。可选权限按服务器实际功能开关和管理要求过滤；自动审核使用 `auto_review`，兼容读取旧 `guardian_subagent` 别名，缺省限制和显式空白名单分别处理。模型和推理选项来自服务器目录。目录中的模型并不保证第三方服务允许使用每一种模型，服务端错误会原样通过安全错误通道显示。

0.2.7 将软键盘的输入框展开与实际 IME 动画目标同步，不再在刚获得焦点时提前展开。关闭输入法的清理只对当前编辑会话生效，前后台切换或重新点击会撤销旧清理，避免返回后新焦点被误清除。重连期间保留当前聊天与已加载图片，允许编辑所属草稿；发送等待连接及聊天恢复完成。相同连接的进行中重连会复用，启动入口复用当前 Activity。显式切换聊天或服务器仍按目标绑定草稿，不混用旧内容。

0.2.8 支持专用首装包免配置激活。手机首次启动生成自己的 SSH 密钥，先在 Android Keystore 保护下保存，再用专用邀请注册公钥；安装包不含 SSH 私钥或模型服务密钥。邀请只绑定一台手机，同一密钥可重试。现有连接不会被覆盖，激活成功后可安装同包名、同签名的普通更新继续使用。专用首装包和普通更新包分开交付，发布脚本拒绝把带邀请的包上传到共用更新目录。详见 [免配置安装](docs/SHARED_INSTALL.md) 和 [0.2.8 验证记录](docs/releases/0.2.8-verification.txt)。

0.2.9 根据 ChatGPT Android 原生实现及录屏适配远程文件底部面板，展示加载、文件名、大小和路径。保存到手机下载目录后提供系统打开；流式下载不再受原先 8 MiB 预览限制。PDF/Word 不再显示乱码或空白全屏页，保留图片和文本预览，并修复带括号/空格的文件链接。原生依据见 [远程文件下载](docs/REMOTE_FILES.md)，目标机检查见 [0.2.9 验证记录](docs/releases/0.2.9-verification.txt)。

0.2.11 修复旧邀请激活失败后换新包覆盖安装的恢复流程，保留同一邀请的设备密钥及已有连接。私有安装包按设备分别签发邀请，普通在线更新不携带邀请。详见 [0.2.11 验证记录](docs/releases/0.2.11-verification.txt)。

0.2.12 在永久删除前识别包含已归档分叉的关联聊天，明确列出受影响范围，确认后按依赖顺序调用服务器原生删除；范围变化或失败时停止。原因与原生证据见 [分叉历史与永久删除](docs/FORK_DELETE.md)。本次仅构建、签名及发布文件校验，按用户要求未执行功能测试。

0.2.13 默认使用 GPT-6.1 Terra / 极高，升级首次强制应用一次；此后按设备和连接保存用户选择，打开旧聊天不覆盖新聊天默认，相同地址的不同连接也不复用聊天缓存。行为说明见 [模型默认值](docs/MODEL_DEFAULTS.md)，当前全部模型窗口与官方证据见 [模型上下文](docs/MODEL_CONTEXT.md)。

0.2.15 修复审计确认的14项问题，并按已核验的 Android 原生参数统一字体、菜单、图标、阴影及深色/高对比主题；图片同路径更新、原图与复制导出不再沿用旧缓存。最终真机与发布记录见 [0.2.15 验证记录](docs/releases/0.2.15-release.txt)。

0.2.14 将正文中的 Markdown 图片接到原生图片组件，SVG 和 PNG 可直接显示在聊天里，并点击放大。支持绝对路径、聊天工作目录下的相对路径及 data URI；普通文件链接继续保持下载/打开语义，代码示例不会触发图片读取。SVG 使用独立矢量解码，原始 SVG 保存保留原文件，复制图片可导出 PNG；缓存按连接隔离。原生依据及边界见 [聊天图片](docs/INLINE_IMAGES.md)，实机记录见 [0.2.14 验证记录](docs/releases/0.2.14-release.txt)。

0.2.21 包含外观的浅色和深色选项、本地 LaTeX 公式排版、Markdown 删除线和粗斜体，并修复清空或发送后首页旧草稿再次出现的问题。

## 已实现的交互类型

- 命令、文件和额外权限审批，以及旧协议审批兼容。
- 阻塞式 `item/tool/requestUserInput`：同一请求 ID 的结构化回答。
- 异步问题：按原生 questionItemId 编码，经 `turn/steer` 回答，校验预期 turn。
- 计划预览、完整阅读、复制/保存、执行、反馈修改和跳过。
- 标准 MCP form / url 请求、类型化字段与请求允许的记忆范围。
- 分页历史、聊天搜索、改名、归档/恢复、附件上传、远程文本/图像预览与保存。

## 明确边界

这里提供的是本地 Codex 手机界面，不连接官方 Cloud 任务或官方手机配对服务。未把 ChatGPT 的所有功能、第三方插件页面或 App Server 全部方法都制作成独立 UI。

Markdown 为本地原生解析的常用子集；差异视图支持文件分组和增删行，没有复用原 App 的 WebView word-diff 库。特殊 MCP 图片字段、用户身份核验和未知 schema 会显示不支持，不会伪造成功。运行结果仍受服务器权限、工具配置与第三方模型服务能力约束。

## 构建

固定 AGP 8.7.3、Gradle 8.9、Kotlin / Compose Compiler 2.2.10、Compose BOM 2024.12.01、compileSdk/targetSdk 35、minSdk 26，Java/Kotlin target 17。

按当前用户环境规范，在 Debian 编译机执行 `scripts/build.sh`。脚本支持被 BuildLab 作业复制执行，使用作业的实际工作目录定位项目。默认构建 Release；`scripts/debug-build.sh` 构建 Debug。签名由环境变量与 Debian 受限签名文件提供，不进入源码。

自行构建若需使用本仓库 GitHub 更新源，必须设置 `CODEX_MOBILE_PUBLIC_RELEASE=1`；不设置时为 SSH 更新通道，读取的是自己配置的 SSH 服务器。自签名 APK 与仓库正式签名不同，不能承诺覆盖安装或接收本仓库签名的 APK 更新，建议普通用户直接使用 Releases。

`app/src/debug` 中的组件预览、输入法/滚动检查、实际图片检查与一次性私有目录凭据导入 Activity 仅供开发测试，Release 不包含这些 Activity。图片检查的原始素材由测试时写入应用私有目录，不打包进 APK。正常用户通过设置页导入连接，不依赖 Debug 入口。

真实升级测试可在 Debian 以 `CODEX_MOBILE_TEST_BASE=1` 构建 Debug variant，其实际安装版本号为 7、名称为 `0.2.5-update-test`；当前源码默认 Release 使用版本号 24（0.2.21）。首装激活验证使用独立测试邀请和 `CODEX_MOBILE_BOOTSTRAP_TEST_BASE=1`，生成 code10 的 `0.2.8-invite-test` Release 基包，避免为测试降级已有手机。两类测试包均严禁发布。更新判断使用 PackageManager 的实际安装版本，不依赖测试 variant 的 BuildConfig 常量。

正式发布在 Debian 使用 `scripts/publish-release.py --help` 所列参数，提供已验证的正式 APK、上一正式版作为签名基线、可信 SSH 主机密钥文件以及版本说明。工具先校验包身份、签名和版本，拒绝可调试/测试包，再上传并校验，最后原子更新版本索引。认证通过任务专用 SSH agent 转发，不复制或长期保存私钥。仅在用户要求交付正式更新时执行发布。

本项目的界面适配约定保存在 `agents.me`，由 `AGENTS.md` 引用：先核对 ChatGPT Android 安装包对应组件，再结合用户截图和录屏实现；不得将此约定写入全局配置。
